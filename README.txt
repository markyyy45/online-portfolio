MARK ANJO B. LLOVIT — PORTFOLIO
=================================

Files:
- index.html: main portfolio page
- style.css: layout, colors, fonts, and responsive styling
- script.js: mobile navigation, current year, and copy-email button
- images/mark-anjo-portrait.png: professional portrait used in the page

To view:
1. Extract the ZIP file.
2. Keep the images folder, index.html, style.css, and script.js together.
3. Open index.html in a browser.

The sample project cards are clearly labeled as concepts and are not represented as deployed projects.
Google Fonts are loaded online; system fallbacks are included.
